# Sistema de Gestión para Ferretería

## Descripción del Proyecto
Sistema de información desarrollado como prototipo funcional para la gestión de inventario y ventas de una ferretería local. Este proyecto fue desarrollado como parte del curso de Ingeniería de Software.

## Características Principales
- ✅ Sistema de autenticación con roles (Administrador/Vendedor)
- ✅ Gestión completa de productos (CRUD)
- ✅ Registro de ventas con actualización automática de inventario
- ✅ Alertas de stock mínimo
- ✅ Base de datos relacional normalizada
- ✅ Interfaz de consola intuitiva

## Tecnologías Utilizadas
- **Lenguaje:** C# (.NET 6.0+)
- **Base de Datos:** MySQL 8.0
- **IDE:** Visual Studio 2022
- **Conector:** MySql.Data (NuGet)
